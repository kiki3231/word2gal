# Word2Gal Skill 实施计划

> **给 Claude：** 必须使用 `superpowers:executing-plans` 子技能，按任务逐项执行本计划。

**目标：** 在仓库内交付可用的 Cursor Skill `word2gal`：用户只提供自然语言，Agent 按 Skill 产出可双击运行的单文件 HTML 视觉小说（立绘风格包约束、标签短反应音、分支与存档）。

**架构方案：** Skill 分步编排（解析→角色卡→资产→填模板），播放器逻辑完全固化在 HTML 模板中；JSON/标签仅内部使用。素材失败回退默认资源，保证可玩。不做后端或大工程。

**技术栈：** Cursor Skill（Markdown）、原生 HTML/CSS/JS 单文件模板、JSON 剧本约定、可选 Node 脚本做剧本校验；立绘/短音由 Agent 按风格包提示词调用可用图像/音频能力（无能力则用默认占位）。

**设计依据：** @docs/plans/2026-07-30-word2gal-design.md 、@Word2Gal.md  
**Skill 规范参考：** Cursor `create-skill` 约定（`SKILL.md` frontmatter + 分步 Instructions）

```markdown
# Word2Gal

## 硬约束
- 用户只提供自然语言；禁止要求用户填写 JSON/标记语法/资源路径
- 不对白全文 TTS；仅标签化短反应音
- 立绘必须走风格包参数卡；禁止自由长描述直出
- 禁止改写播放器核心 JS；只填充模板占位符
- 素材失败 → 默认资源，HTML 仍须可玩

## 工作流（概要）
1. 收集/确认自然语言剧情与角色
2. 编译内部剧本 JSON（见 reference）
3. 蒸馏角色卡并选用风格包
4. 生成或回退立绘/短音
5. 填入 templates/player-basic.html 并写出成品
6. 自检清单

## 模式二
若用户要求加强演出，用同一剧本填 templates/player-advanced.html（若尚未存在则先用 basic 并说明）。
```

**步骤 1：写失败测试（校验器尚不存在或规则未实现）**

`validate-script.test.mjs` 用 Node 内置 `node:test`：

- `valid-script.json` 应 exit 0 / 返回 ok
- `invalid-script.json`（缺 nodeId、choice 指向不存在节点、dialogue 无 emotion）应失败

**步骤 2：运行测试，确认失败**

```bash
node --test .cursor/skills/word2gal/scripts/validate-script.test.mjs
```

预期：**FAIL**（模块或规则未实现）

**步骤 3：编写 schema 文档 + 最小校验实现**

`script-schema.md` 说明节点类型：

- `meta`：title、stylePack
- `nodes[]`：`id` + `type` ∈ `scene|narration|dialogue|choice|ending`
- `dialogue`：`speaker`、`text`、`emotion`（枚举）、可选 `voiceTag`
- `choice`：`options[{label, goto}]`
- 全剧 `nodeId` 唯一；所有 `goto` 必须存在

`validate-script.mjs`：读 JSON 文件路径，打印错误列表，非法则 `process.exit(1)`。

**步骤 4：再跑测试确认通过**

```bash
node --test .cursor/skills/word2gal/scripts/validate-script.test.mjs
```

预期：**PASS**

**步骤 5：提交**

```bash
git add .cursor/skills/word2gal/reference/script-schema.md .cursor/skills/word2gal/scripts
git commit -m "feat: add word2gal script schema and validator"
```

### 任务 4：模式一播放器模板（可玩空壳）

**涉及文件：**
- 新建：`.cursor/skills/word2gal/templates/player-basic.html`
- 新建：`.cursor/skills/word2gal/scripts/fixtures/demo-embed.json`（可内嵌进模板做自测）

**步骤 1：实现单文件播放器骨架**

占位符约定（Agent 只替换这些，不改逻辑），例如：

```html
<script id="w2g-script" type="application/json">__SCRIPT_JSON__</script>
<script id="w2g-assets" type="application/json">__ASSETS_JSON__</script>
```

`__ASSETS_JSON__` 形如：`{ "chars": { "hero_neutral": "data:image/png;base64,..." }, "sfx": { "surprised": "data:audio/mpeg;base64,..." }, "bgs": { ... } }`

功能必须具备：

- 显示背景与立绘（按 speaker + emotion 取图，缺失用 default）
- 打字机文本、点击/空格推进
- choice 分支、ending
- localStorage 存读档（存 nodeId）
- 音量开关；有 voiceTag 则在用户首次点击后播放短音

**步骤 2：用 fixture 手动验证**

将 `demo-embed.json` 填入模板，用浏览器打开：走完主线、选分支、存读档、缺立绘不白屏。

**步骤 3：提交**

```bash
git add .cursor/skills/word2gal/templates/player-basic.html .cursor/skills/word2gal/scripts/fixtures/demo-embed.json
git commit -m "feat: add basic HTML visual novel player template"
```

## 风险与注意事项

- 图像/音频 API 因环境而异：Skill 必须写明「无工具时用 defaults」，避免流程卡死
- 严防 Agent 重写播放器 JS：模板注释 + Skill 硬约束双保险
- 单文件 base64 体积：首版限制表情数与短音秒数；必要时改为同目录相对路径并说明分享方式
- 保持 YAGNI：先 1 个风格包 + basic 模板；advanced 可极简或文档占位
