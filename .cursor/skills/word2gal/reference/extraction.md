# 文章抽取（内部）

> 用户只给自然语言文章。本文件定义 Agent 必须抽出的信息；用户不填表。

## 目标

把「有角色、有场景、有对话」的文章，变成制作 HTML 视觉小说所需的结构化素材（仍只存在于 Agent 内部）。

## 容量

单次输入遵守 `SKILL.md`「单次容量软上限」。超长文先拆章再抽取，勿一次抽完整本。

## 必抽字段

### 角色 `characters[]`

对每个出场说话或对情节重要的人物：

| 内部字段 | 来源 |
|----------|------|
| `displayName` | 文中称呼 |
| `aliases` | 别名/昵称 |
| `appearanceClues` | 文中外貌句（原文摘录） |
| `personalityClues` | 性格/语气线索 |
| `isOC` | 是否像原创角色（文内自创、无通行设定） |
| `searchQuery` | 用于网查的查询词（作品名+角色名，或「同人 OC + 外貌关键词」） |

### 场景 `scenes[]`

| 内部字段 | 来源 |
|----------|------|
| `name` | 地点名 |
| `timeMood` | 时间与氛围（黄昏、雨夜等） |
| `visualClues` | 文中环境描写 |

### 叙事节拍 `beats[]`

按阅读顺序拆成：旁白 / 对话 / 场景切换。对话保留说话人与原句（可轻微润色标点，不改剧情含义）。

### 分支 `branches`

- 文中写了「如果…」「二选一」→ 做成 `choice`  
- 完全没有 → 单线到底，可加一个自然收束 ending  

## 准确度规则

1. **不发明剧情**：文章没有的情节、选项、角色关系不要加（除非用户追问后同意）。  
2. **对话归属**：说不清谁说的，追问或标为旁白。  
3. **次要路人**：无对白且无戏份可不出立绘，合并进旁白。  
4. **交付前**：在摘要里用自然语言列出「识别到的角色 / 场景 / 是否有分支」，方便用户核对。

## 输出到下游

抽取结果用于：

- `character-lookup.md`（网查与立绘）  
- `emotion-and-sfx.md`（成色与拟声）  
- `script-schema.md`（编译剧本 JSON）
