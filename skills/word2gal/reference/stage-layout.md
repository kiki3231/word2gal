# 舞台站位：标准 Gal 七分身左右对位

> 内部约定。对标常见 Galgame（如对话场景）的立绘构图，供生图与播放器取景共用。

## 这是什么站位

**七分身（cowboy shot）左右前景对位**：

| 要素 | 约定 |
|------|------|
| 取景 | 头～大腿中段；脚不入画 |
| 水平 | 左位 / 右位各一人（本 skill 默认双人舞台） |
| 纵深 | 说话人前景高亮；非说话人同框但压暗（略退后感） |
| 对白框 | **有意遮住立绘下缘**（腰～大腿），脸与手势留在框上方可读区 |
| 姿态 | 手势落在胸～脸高度，保证被对白框裁切后仍看得清 |

三人中景后置（左前/中后/右前）是进阶变体；本 skill **软上限内不做三人同框强制**，仍用左右双槽。

## 对 Agent 的含义

1. **生图**：按七分身裁切出差分；姿态手势写在上半身可读区（见风格包 pose 表）  
2. **播放器**：立绘底部探入对白框区域，由 `#ui` 叠层遮挡下缘——**不要**把全身脚抬到框外完整露出  
3. **差分**：同一角色多 emotion 须换脸+换姿；禁止全员同一 idle 站姿只换脸  

## 与资源命名

站位不改变 `chars.{id}_{emotion}` / `dialogue.side`（`left`\|`right`）约定。
