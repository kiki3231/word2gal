# 文章抽取（内部）

> 用户只给自然语言文章。本文件定义 Agent 必须抽出的信息；用户不填表。

## 目标

把「有角色、有场景、有对话」的文章，变成制作 HTML 视觉小说所需的结构化素材（仍只存在于 Agent 内部）。

## 容量

单次输入遵守 `SKILL.md`「单次容量软上限」。超长文先拆章再抽取，勿一次抽完整本。

## 必抽字段

### 角色 `characters[]`

对每个出场说话或对情节重要的人物：

| 内部字段 | 来源 |
|----------|------|
| `displayName` | 文中称呼 |
| `aliases` | 别名/昵称 |
| `appearanceClues` | 文中外貌句（原文摘录：发型、发色、瞳、身高体型、服饰、标志物） |
| `personalityClues` | 性格/语气/神态线索（影响基准脸，勿只记「性格标签」） |
| `ageClues` | 年龄/学段/身份线索（小学生、高中生、大人、老师等原文） |
| `isOC` | 是否像原创角色（文内自创、无通行设定） |
| `searchQuery` | 用于网查的查询词（作品名+角色名，或「同人 OC + 外貌关键词」） |

### 场景 `scenes[]`

| 内部字段 | 来源 |
|----------|------|
| `name` | 地点名 |
| `timeMood` | 时间与氛围（黄昏、雨夜等） |
| `visualClues` | 文中环境描写 |

### 叙事节拍 `beats[]`

按阅读顺序拆成：旁白 / 对话 / 场景切换。

**文本保真：**

- 对白、旁白、内心独白一律使用**用户原文**，禁止压缩、改写、润色、合并段落或「换一种说法」  
- 仅允许：按播放节奏把原文**原样切开**成多个节点；标点与用词保持原样  
- 禁止把两段原文收成一句摘要；禁止删掉文中的停顿、重复、口语（如「万一……万一……」「我想…」）

## 原文覆盖校验

1. 将用户原文落盘为纯文本（如 `output/<短目录>/source.txt`），与 `script.json` 一并校验。
2. **机器校验（Bake 前须通过）：**
   ```bash
   node skills/word2gal/scripts/validate-coverage.mjs <source.txt> <script.json>
   ```
   脚本对 `dialogue` / `narration` / `ending` 的 `text` 做空白归一化后，要求其为原文子串。
3. 任一节点未命中 → 补节点或修正 `text` 后再 Bake；**禁止**用改写句「意思接近」蒙混。
4. 交付摘要写明：「原文未删减，仅按节奏切开；覆盖校验已通过（validate-coverage OK）」。
5. 触及软上限时：拆章分次生成，**禁止**用摘要浓缩规避；拆章时复用角色卡见 `character-card.md`。

### 分支 `branches`

- 文中写了「如果…」「二选一」→ 做成 `choice`  
- 完全没有 → 单线到底，可加一个自然收束 ending  

## 准确度规则

1. **不发明剧情**：文章没有的情节、选项、角色关系不要加（除非用户追问后同意）。  
2. **不压缩原文**：见上「文本保真」；剧本里的 `text` 必须能在原文中找到对应句子/段落（子串或整段切开）。  
3. **对话归属**：说不清谁说的，追问或标为旁白。  
4. **次要路人**：无对白且无戏份可不出立绘，合并进旁白。  
5. **人物细节优先摘全**：外貌、神态、年龄/学段相关句尽量原文摘入线索字段，供下游对照与年龄锁使用（见 `character-lookup.md`）。 
6. **交付摘要**：用自然语言列出「识别到的角色 / 场景 / 是否有分支」，便于用户核对。

## 输出到下游

抽取结果用于：

- `character-lookup.md`（深度分析、网查对照与立绘）  
- `emotion-and-sfx.md`（成色与拟声）  
- `script-schema.md`（编译剧本 JSON）
